How editing works here

  • Click a value to fill it in. The same value changes everywhere it is used, and in the Values list.
  • Click a sentence to change its wording for this patient. «Restore original» undoes it.
  • Hover a value to see how it is stored (@bedrest_days).
  • If a sentence cannot be shown safely this way, it opens as plain text instead.
  • Nothing is saved until you press Save or Save & preview.
